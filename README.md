# Kedi Felsefesi Üreten Makine

## Giriş

Bu proje, insanlık tarihinin en derin varoluşsal krizlerinden birine çözüm önermektedir: "Neden kediler bu kadar derin düşünüyor gibi görünüyor?"

Evet, sevgili okuyucu. Kediler sadece miyavlamaz. Onlar evrenin sırlarını fısıldar. Bu makine, o fısıltıları Türkçe felsefi cümlelere dönüştürür. Her çalıştırmada yeni bir kedi düşüncesi üretilir. Bazıları anlamsız görünebilir. O da felsefenin bir parçasıdır.

## Kurulum

Python 3 yüklü olsun yeter. Başka hiçbir şey gerekmez. Çünkü bu makine, gereksizlik üzerine kurulmuştur.

```bash
python kedi_felsefesi.py
```

## Nasıl Çalışır?

1. Program başlar.
2. Rastgele kelimeler seçer.
3. Onları birleştirip "derin" bir cümle üretir.
4. Ekrana basar.
5. Sen düşünürsün: "Bu ne lan?"
6. O da felsefedir.

## Örnek Çıktılar

- "Kediler uyurken aslında evrenin titreşimlerini dinler ve kahve içer gibi yaparlar."
- "Bir kedi düşerse, düşme miyavı mıdır yoksa varoluşun sessiz protestosu mudur?"
